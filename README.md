# 简历有方

面向求职者的简历工作台，先找到“经历写得空、成果不明确、岗位不匹配”的具体问题，再逐项改善表达。前端采用苹果风格的留白、清晰层级和轻量卡片；使用 uni-app、Vue 3 和 TypeScript，同一套业务界面支持 H5 与微信小程序。

这是可本地运行和部署的基础工程：邮箱注册登录，或在短信配置启用后使用手机号验证码登录/注册后，简历编辑与保存、规则诊断、岗位关键词检查、建议对比与确认构成当前闭环。未启用模型时使用透明规则；服务端支持通过百炼 API 提供诊断建议，须在服务端配置并由用户确认个人信息处理告知。参考分和关键词覆盖仍由规则计算，不代表招聘结果或真实 ATS 评分。规则报告会检索原创岗位参考卡，百炼启用后可用该卡作为生成上下文并校验引用。微信小程序支持静默微信免登（按 openid 建立/复用账号）。小程序虚拟支付、网页微信扫码和支付宝网页支付按服务端配置提供。

当前优先完成功能与资料收集。用户正在办理备案与个体工商户，完成后再接入相应正式平台能力。2026-10-27 用户进一步授权将当前版本部署到既有服务器并上传 [huangfeiyang05/resume](https://github.com/huangfeiyang05/resume)，后续代码更新同步 Git 和服务器；具体完成情况以每次发布校验记录为准。新增简历历史版本对照与确认恢复；求职资料以应届生为主，覆盖现有 16 个专业，提供原创简历准备清单、复习提纲和官方招聘入口。资料说明与核查记录见 [求职资料库](docs/career-library/README.md)。

“公司与岗位”增加独立企业资料查询：按行业、性质、地区、岗位方向、学历、批次和招聘对象组合筛选，支持多关键词、服务端分页及日期核对。2026-11-07 起，工作台按服务端有效会员分级：简历优化入口为初级及以上，求职助手、公司岗位、招聘入口、复习资料和投递计划为高级；取代此前测试阶段向登录用户共享的安排。企业目录位于被忽略的 `.data/company-catalog.json`，原始资料、导入报告及备份在 `.data/company-imports/`，均不随源码或静态资源发布；只有核对后的企业资料进入受会话和会员权限保护的查询接口。整理边界和导入命令见 [企业资料库](docs/company-library.md)。

公网排查记录（2026-10-26）：用户确认域名尚未完成 ICP 备案，`www.youfangcv.site` 与根域名的公网 HTTPS 握手被关闭；当次服务器内部 HTTPS 和应用健康检查正常。该现象高度符合腾讯云未备案阻断，当次公网访问未恢复。后续每次发布分别检查源站与公网，代码部署成功不表示备案完成或公网恢复。排查记录、官方入口与恢复验收见 [部署说明](docs/deployment.md#公网故障与备案前置条件)。

## 本地启动

环境：Node.js **22.13.0 或更高版本**、npm。首次安装：

```sh
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。该命令同时启动 H5 与本地 Node API；H5 的 `/api` 请求由 Vite 转发至 `http://127.0.0.1:3001`。开发端口被占用时，先停止占用进程。

也可分别运行：

```sh
npm run dev:api
npm run dev:h5
```

本地 API 将账号、会话、简历及诊断记录保存在 `.data/` 中，重启后可继续读取。当前采用单进程 JSON 持久化，已接入服务端会话及业务资源的用户归属检查；这不等于已经迁移 MySQL 或通过生产级并发验收。部署必须使用 HTTPS，配置与维护方式见 [部署说明](docs/deployment.md)。`.data/`、`.env*`、`.deployment/`、私钥、依赖和构建产物已加入忽略规则；账号数据、简历原件、个人信息、数据库备份和密钥不得上传 Git。

## 注册与登录

首次使用通过项目内的登录页面注册邮箱和密码（新密码须为 6 至 16 位，只能使用字母、数字和符号，不能包含空格和中文；登录仍接受符合旧规则的密码）。启用邮件服务后，注册须先获取并填写邮箱验证码，成功后建立已验证账号并进入自己的工作空间；已有账号可直接登录，在“我的”查看账号、补做邮箱验证并退出。网站不再使用浏览器的共享用户名/密码弹窗。服务端使用 scrypt 保存密码哈希，会话只持久化随机令牌的哈希，密码及原始令牌不进入响应日志。

H5 使用 HttpOnly、SameSite 的会话 Cookie，线上加上 Secure；不把 H5 会话令牌放入前端本地存储。小程序邮箱登录使用服务端签发的 Bearer 令牌，由客户端保存并随 API 请求发送。会话最长有效 7 天，退出后服务端撤销；失效时回到登录页面。简历、报告、诊断任务与建议应用均以可信会话中的用户身份检查归属，客户端传入其他 `userId` 不能获得访问权限；前端草稿及工作空间缓存也按账号隔离。

邮箱验证码用于注册、已有账号邮箱验证、找回密码和已登录账号绑定新邮箱，各用途相互隔离。验证码为 6 位数字，有效期 10 分钟，单次使用，重发至少间隔 60 秒，并限制发送频率和错误次数。找回密码成功后不自动登录，服务端会撤销该账号的全部旧会话，需要使用新密码重新登录；原账号的简历和报告保留。已有未验证账号不会被自动标为已验证，须先凭原密码登录并完成本人邮箱验证，之后才能使用找回密码，避免通过误填邮箱认领旧账号资料。

邮件能力由服务端配置决定，页面通过 `/auth/providers` 读取是否开放。本机默认关闭邮件时仍可使用邮箱密码演示模式；生产服务要求验证码注册，邮件关闭或配置失效时明确拒绝注册，不会静默降级为无验证码注册。SMTP 发送失败会明确返回失败；SMTP 服务器接受邮件不等于已经送达收件箱。微信小程序启动时可用 `wx.login` 的 code 静默登录；首次登录按 openid 创建账号，之后复用同一账号，不会自动合并已有邮箱/手机账号。手机号验证码登录/注册和同账号手机号、邮箱绑定已接入代码，短信默认关闭，未配置时入口明确显示未开放。已认证的非个人主体可单独启用微信手机号实时验证。小程序用户可用当前微信身份绑定邮箱，并主动保存头像和昵称。头像按账号鉴权，保存在受忽略规则保护的 .data/account-avatars 目录，随发布前的私有备份保留。

原单工作空间中没有归属的历史简历不会自动送给第一位注册用户；兼容迁移会保留为旧工作空间数据，对新注册账号不可见。需要迁移这些资料时应另行核实归属，不按“谁先注册”认领。

## 管理后台

「企业资料」支持直接填写单条记录、上传 UTF-8 CSV／JSON，以及搜索并修改已发布的单条记录。核对新增或修改预览后确认发布，也可回滚最新后台操作。历史目录、版本快照和操作记录保存在 Git 忽略的 `.data/`。流程见 [企业资料库](docs/company-library.md#后台批量导入)。

网页后台入口为 `/admin/`。提供运营概览、用户与会员、诊断与用量只读查询，以及招聘岗位、复习资料和官方招聘入口的草稿、预览、发布、下架、回滚和操作记录。复习资料支持 10 MB 以内的 PDF／Word（.docx）和 30 MB 以内的 H.264 MP4 视频，原件写入 Git 忽略的 `.data/career-files/`，随资料版本保留。管理员以已验证的邮箱和密码单独登录，授权来自服务端的 `ADMIN_USER_IDS`，留空时入口保持锁定。使用方法见 [管理后台说明](docs/admin.md)。

在「用户与会员」可分列查看已绑定的完整邮箱和手机号。「支付订单」支持查询并对已核对的会员订单发起全额退款，渠道确认成功后撤销本单权益。

「会员价格」支持按环境预览、发布和查看历史。运行 `npm run test-env` 可启动本机测试版和测试后台，使用 Git 忽略的 `.test-data/` 与模拟支付。使用说明见 [测试版与公开版](docs/admin.md#测试版与公开版)。

## 邮件服务配置

邮件发送由服务端 SMTP 适配器承接，前端不持有 SMTP 授权码或发信密钥。当前 163 配置使用 `smtp.163.com:465` 和 TLS；用户名为完整发信邮箱，认证凭据为客户端授权码。配置项为 `MAIL_ENABLED`、`MAIL_PROVIDER=smtp`、`SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASSWORD`、`MAIL_FROM` 和 `MAIL_CODE_SECRET`，详见 [部署说明](docs/deployment.md)。

邮箱密码找回继续只使用已验证邮箱。短信启用后，已绑定手机号可凭验证码登录同一账号；未绑定号码首次验证会创建独立账号。已有邮箱账号应先登录后绑定手机号，避免另建账号。简历中填写的手机号不构成归属证明，系统不自动合并账号。

本机私密配置位于已忽略的 `.deployment/mail-163.env`，服务器配置位于 `/etc/resume-youfang/runtime.env`，均保持 `0600` 权限。不要将授权码写入 `VITE_` 变量、静态文件、构建包、日志或 Git。`MAIL_CODE_SECRET` 是独立生成的至少 32 随机字节密钥，用于验证码 HMAC，不能复用 SMTP 授权码；更换后原有未消费验证码需要重新获取。

账号、会话、简历、报告与邮件/短信挑战保存在版本 3 的 JSON 数据中；验证码只保留与邮箱、用途及挑战 ID 绑定的 HMAC 哈希，不保存明文。测试注入假发信器验证业务状态，不发送真实测试邮件；SMTP 连接验证只证明连接和认证可用，最终收件需由用户实际确认。

## 手机号与短信配置

已接入腾讯云短信发送适配器、手机号验证码登录/自动注册及“我的 → 账号登录方式”绑定入口。同一账号可绑定手机号和邮箱，绑定需当前密码或当前已绑定手机证明，再验证新标识；手机号账号绑定邮箱时须设置登录密码。没有邮箱的账号不生成假邮箱或默认密码，绑定不改变账号 ID、简历或会员。已属于其他账号的手机号/邮箱不能直接绑定，没有改绑、解绑或自动合并。

短信默认 `SMS_ENABLED=false`、`SMS_PROVIDER=tencent`。启用需要真实的 `TENCENT_SMS_SECRET_ID / SECRET_KEY / SDK_APP_ID / SIGN_NAME / TEMPLATE_ID / REGION`，临时凭据可带 `TOKEN`，另须独立的 `SMS_CODE_SECRET`（至少 32 字节）和 `SMS_DAILY_LIMIT`（默认 100 次/滚动 24 小时，失败提交也计入）。密钥只存受限服务器环境，不能用 `VITE_`、聊天密钥或占位值启用。本轮尚缺已确认的 SDKAppID、审核通过签名和模板 ID，不修改服务器业务配置、不发送真实短信。资质审核通过且关联签名为 0 的截图不能证明可以发送。

短信验证码为六位、5 分钟有效，60 秒冷却，单号每小时 5 条/24 小时 10 条、单 IP 标签每小时 10 条/24 小时 30 条，全局 100 次/24 小时，2 个发送并发，错误 5 次锁定。供应商确认提交后才可使用，失败和超时不自动重试，也不代表免费或最终送达。完整接口、配置、同账号绑定及数据回退边界见 [手机号与短信](docs/phone-auth.md)。

## 预览与使用

1. 移动端底部、桌面端顶部设“首页、工作台、权益、我的”四个入口。首页按简历内容、优化要求、简历布局向下排列，诊断报告直接显示在同一页；“我的”管理已保存简历，也可用示例内容体验。
2. H5 的新建／编辑简历弹窗可点击“上传 Word / PDF”，在本机提取 `.docx`、文字型 PDF、TXT 或 Markdown 的正文；首页原导入入口也进入同一编辑流程。文件上限 10 MB、PDF 最多 50 页、提取正文最多 50,000 字符。旧版 `.doc` 请先另存为 `.docx`；扫描 PDF 不支持 OCR，加密或损坏文件会提示恢复方式。
3. 保存后在首页运行规则诊断，完成后滚动至下方报告；独立填写的目标岗位会用于本次分析，也可添加 JD 查看逐条核对清单、简历原文及待核实的资格条件。关键词命中仅表示文本覆盖。
4. 对照原文逐项审核建议；涉及待补充事实时，填写真实信息并确认后应用。应用会更新简历修订号，过期分析不能直接覆盖新内容。
5. 微信端的导入、新建和编辑弹窗可从微信聊天选取 Word（.docx）或文字型 PDF，也可粘贴正文。手机“文件”或下载目录里的简历可用手机浏览器打开 [简历有方网页版](https://www.youfangcv.site)，登录同一账号后点击“上传 Word / PDF”。仅用微信登录的用户可在“我的”绑定邮箱，短信登录开放后也可使用已绑定的手机号。

2026-11-07 的弹窗导入会把文字填入当前简历草稿，不自动保存为新简历或发起诊断。正文为空或仍是默认填写骨架时直接填入；已有正文先显示识别结果，用户点击“替换为识别正文”后才替换，也可保留现有正文。自定义简历名称和目标岗位保留；仅新建简历的默认／空名称可采用文件名。解析结果只提取正文，不保留 Word／PDF 原有排版，也不根据文件补造经历或资质。

H5 在浏览器内解析。微信聊天文件经确认后临时上传，服务端提取正文，完成、取消或过期后清理原件。文件导入不调用模型。草稿按账号保存在本机，点击“保存简历”才将正文同步到服务端。H5 解析上限 30 秒，微信上传和解析合计上限 120 秒。取消、超时、失败、关闭编辑器或切换简历后，编辑器会丢弃迟到的结果；已有正文须在预览后确认替换。点击“保存并诊断”仍按原有告知与额度规则处理。

上传微信体验版前，在微信公众平台《小程序用户隐私保护指引》声明“选中的文件”，用途可填“用于读取你选中的 Word 或 PDF 简历，临时上传以提取正文”。体验版用 iOS、Android 各验证聊天文件选择、上传确认、取消及保存。

“简历版本记录”可从当前简历和“我的”进入，对照当前已保存正文与历史内容，确认后恢复为新版本。每次实际编辑、建议应用和恢复都会保留历史；未保存草稿保留。旧数据只从当前已知修订号开始记录，无法补造更早内容。恢复后需重新诊断，重复请求不会重复增加版本。

“简历布局”现在可直接打开“预览我的简历”，按已保存正文中的明确栏目展示完整排版。教育/学历、工作与实习、项目、技能、证书与荣誉分别分区；支持“工作/实习经历”“技能与证书”等组合标题，保留原文及栏目正文内部的顺序，不根据岗位要求补造资质。双栏风格将技能、证书、自我评价等辅助栏目放侧栏。预览可切换三种风格并返回编辑；缺失栏目需要用户补充真实内容，预览不是简历自动补全。“预览与导出”可选择 Word（.docx）或 PDF，文件由服务端按已保存正文和所选版式生成并以下载返回：H5 在浏览器下载，微信小程序写入本地后打开文档；两种格式都保留原文内容，不补写资质。

首页只保留一个“简历布局”区域，“发现 → 简历布局”也定位到这里。三款统一为经典简约（黑白）、现代留白（浅蓝）、专业商务（深蓝）：点击简历图片或名称选择布局，点击下方“查看版式”展开完整预览，“下载 Word”获取可编辑 DOCX。所选风格同时用于“预览我的简历”和导出的 Word / PDF 文件。Word 模板包含可编辑个人信息、30×40 mm 照片位，以及教育、技能、工作/实习、项目、证书与荣誉、自我评价六个栏目；内容均为填写提示，下载后在 Word 中编辑。当前“下载 Word”获取的是公开占位模板文件；已保存正文的 Word / PDF 导出在“预览我的简历 → 预览与导出”中选择格式生成。

三款设计分别适配自 Reactive Resume 的 Onyx、Azurill、Chikorita 开源模板（MIT）：经典简约使用黑白单栏与细线；现代留白采用浅蓝左侧栏与白色主栏；专业商务采用白色主栏和深海军蓝右侧栏。侧栏用于已有技能、证书、自我评价等栏目，正文内容不补写；没有侧栏内容时使用完整主栏。网站正文预览与导出保留原文内容，不生成姓名、联系方式或照片，窄屏回到单栏。来源、模板对应关系及许可见 `docs/resume-template-designs.md` 和 `THIRD_PARTY_NOTICES.md`。

三份 Word 原稿保存在 `outputs/简历Word模板/`，公开占位模板与 PNG 预览放在 `src/static/resume-templates/`，目录由 `src/data/resumeTemplates.ts` 管理，生成脚本为 `scripts/build-resume-word-templates.py`。`outputs/` 和 `.data/` 继续忽略；不得将用户填写后的简历或真实照片复制到公开静态目录。更新模板时同步更新对应 Word 和整页预览。

底部“工作台”直接进入求职工作台，原“发现”中间页已移除。当前身份不能使用的入口显示浅雾化锁态，点击提示升级所需等级，并可前往“权益”。界面权限来自 `GET /api/v1/membership/workbench` 的服务端有效会员记录；企业查询与受限写入还由服务端检查，权限不足返回 403，非高级的 `/career` 不下发岗位、资料、入口、收藏或投递记录。权限读取失败显示重试，不当作升级理由。

初级及高级可从工作台进入简历优化，复用版本绑定的分析、对照审核和确认应用流程；免费用户仍可在首页进行本地规则检查、查看报告、确认应用，创建及编辑简历、使用基础模板并导出。高级工作台提供求职助手（本地规则检索）、岗位筛选与收藏、个人岗位添加、资料正文阅读、绑定简历版本的投递计划和手动进度记录。助手按本地规则查询近期核对过来源的具体岗位、历史企业资料和本人目标岗位，对话按账号保存在本机，不上传服务端；受限后仍可清理本机对话。本人旧岗位及投递记录的删除接口继续按归属校验，但本轮未新增非高级读取旧记录的界面。首批按 16 个专业提供 32 份应届生准备材料、18 个官方招聘入口和 36 条具体岗位摘要。来源与申请状态以官网为准。自动代投尚未接入。

两档会员默认月价为初级 ¥9.90/月、高级首次付费 ¥24.90/月（原价 ¥29.90，首充优惠）；小程序购买使用微信虚拟支付，iOS 走 Apple 内购。网页使用微信扫码或支付宝。未开通的渠道保持关闭。AI 已采用实际 Token 周额度，初级后台配置 200,000、高级 800,000 Token；界面只显示本周剩余百分比和北京时间刷新时刻，不展示绝对额度、固定次数或单次消耗。初级在有效期内升高级只补两档月价差额，升级经服务端确认支付成功后立即生效，并在原到期日基础上顺延一个自然月，原剩余天数保留；无对应日期时取下个月月底的同一时刻。会员为手动续费，完整规则见 [会员机制](docs/membership.md)。**支付是否开放由服务器 `WECHAT_VIRTUAL_PAY_*`、`WECHAT_PAY_*`、`ALIPAY_*` 配置决定：未配置时不扣钱、不通过页面发放会员；配置后支付成功仍须服务端回调验签核单才发放。无可信服务端会员记录时按免费身份处理，不伪造余额或到期日；工作台只解锁有效等级对应功能，有效会员记录会执行周额度，过期记录拒绝新的模型调用。** 接入与密钥配置见 [微信支付与支付宝网页支付接入](docs/payment.md)。

高级会员可阅读复习资料、查阅官方招聘入口，核对真实公告后录入个人目标岗位，并自行记录投递进度。底稿默认来自 `server/assets/career/catalog.json`，存在 `.data/career-catalog.json` 时读取自定义底稿。后台发布按条目应用于底稿，草稿、发布历史及审计保存在 `.data/resumes.json`，沿用现有 Git 忽略和受限备份。格式与版本规则见 [求职工作台](docs/career-workspace.md)。

## 微信开发者工具

```sh
npm run build:mp-weixin
```

使用微信开发者工具导入 `dist/build/mp-weixin`。在 `src/manifest.json` 的 `mp-weixin.appid` 填写自己的小程序 AppID，然后重新构建；仓库不包含可直接上线的主体配置。

小程序没有 H5 的 Vite 代理，调用 API 需要配置构建时变量 `VITE_API_BASE_URL`。例如，在本机开发者工具联调时：

```sh
# 终端 1
npm run dev:api

# 终端 2，仅本机开发者工具联调
VITE_API_BASE_URL=http://127.0.0.1:3001 npm run dev:mp-weixin
```

开发者工具导入监听构建输出 `dist/dev/mp-weixin`；本机 HTTP 联调需要在工具的开发设置中暂时关闭请求域名校验。真机的 `127.0.0.1` 指向手机自身，不能访问电脑上的 API。

小程序连接服务器时，将 `VITE_API_BASE_URL` 设为对应的 **HTTPS** API 地址，并按小程序环境配置请求域名；邮箱登录后的请求携带当前账号的 Bearer 令牌。微信小程序已接入 `wx.login` code 交换与静默免登；服务端必须配置小程序 AppID/AppSecret（WECHAT_APP_ID 与 WECHAT_APP_SECRET，或沿用同 AppID 的旧微信支付身份配置）。未配置时可使用邮箱登录。微信手机号授权及头像昵称还需在小程序后台声明相应隐私用途。当前没有实现 `wx.cloud.callContainer`。`VITE_` 变量会进入客户端包，只能放公开配置，不能放模型密钥或小程序服务端密钥。

微信端的模板预览使用包内图片；Word 文件下载另需设置 `VITE_TEMPLATE_BASE_URL` 为可访问的 HTTPS 网站根地址（可带部署子路径，末尾不含 `/static/`），该网站须提供同一套 `static/resume-templates/*.docx`。服务器配置使用 `https://www.youfangcv.site` 提供公开占位模板；截至 2026-10-26 该域名公网 HTTPS 不可达，待备案完成并验收恢复后才能作为可用下载地址。下载后通过微信文档查看器打开，并提供文档菜单。按目标小程序配置文件下载域名后再做真机验收；未配置地址或下载/打开失败会明确提示到网页版“发现”下载，该备用入口也依赖网站公网恢复。不能用电脑的 `127.0.0.1` 代替真机地址。

## 验证与构建

代码同步约定：后续本项目代码或随包资料更新完成后，先执行相关检查、测试和构建，审查提交范围，再提交并推送到 `huangfeiyang05/resume`，随后将同一版本发布到现有服务器。沿用新发布目录、保留上一版和受限数据备份的流程，不覆盖服务器用户数据、运行时配置或密钥；不强推覆盖远端改动。推送与部署分别校验并报告，任一未完成时明确保留待办。用户某轮要求只本地修改、只审查或不部署时遵从该轮要求，无需为既有范围重复确认。详细流程见 [部署说明](docs/deployment.md#代码与服务器同步约定)。

本机配置保存在 `config/application-local.yaml`（已忽略，权限 `0600`），示例见 `config/application.example.yaml`。Node API 启动时读取 `bailian.enabled / api-key / base-url / model`；默认示例关闭模型。修改后重启 API。可用 `BAILIAN_ENABLED`、`DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL`、`DASHSCOPE_MODEL` 服务端环境变量覆盖；不能使用 `VITE_` 前缀存储凭据。配置结构为本项目自定义，未来 Spring AI 需要显式映射。

启用后首次点击分析显示简短百炼处理告知，同一次页面会话内不再重复询问；页面重载后需重新确认。手机号、邮箱、身份证号自动遮盖，姓名、单位与其他经历仍可能含个人信息；脱敏不是匿名化。服务端向北京地域百炼发送用于取证的脱敏简历片段、岗位和 JD，使用 JSON 输出、45 秒超时、单并发及输出大小限制，不自动重试收费请求。失败明确返回错误，不伪装规则成功；取消仅停止本地处理和保存，不保证供应商撤销已产生的调用费用。当前默认 `qwen-plus-2025-12-01`，首版由 AI 定位问题、引用原文并提出缺失事实问题；服务端保留原句生成待补占位，不让模型直接代写经历。模型建议均须核实，占位内容填写完整后才能应用。事实语义无法仅凭程序完全验证，必须人工审核。

诊断任务、固定输入快照、请求幂等标识与模型用量账本现已保存在服务端 `.data/` 的版本 3 JSON 中；重启保留任务 ID，将未完成任务标为 `JOB_INTERRUPTED`，不自动重复调用模型。客户端按账号保留提交状态不明的幂等标识，重连复用请求或直接查询已知任务。仍只支持单进程原子文件写入，不是 MySQL 或多实例生产队列。模型开关和密钥配置表示可尝试调用，`health.aiConfigured` 不证明账户余额或模型权限有效。

额度按供应商实际输入加输出 Token 结算；已有有效用量时，超时、取消、内容校验或保存失败仍计入额度。未派发的请求释放预占；派发后缺失有效用量则保留待核对，阻止该账号新模型调用，不能按字数估扣。规则检查、历史报告、确认应用和导出不消耗模型额度。首次可信激活起每 7 天刷新，升级及连续续费保留周起点与已用量。内部会员激活方法只接受服务端验签核单后的可信支付事件；没有普通用户可直接调用的发放入口，客户端支付成功不能发放会员。

未知用量可凭可信供应商证据，通过发布包的 `ops/reconcile-ai-usage.sh` 在线下停服、部署锁和受限备份保护下核对；不自动对账或自动释放，本次发布不运行线上核对、不变更模型或支付配置。完整规则与证据格式见 [AI 周额度](docs/ai-quota.md)。

同一 YAML 的 `aliyun` 节保存 AccessKey ID / Secret，但当前服务**不读取该节、不调用云资源 API**；百炼模型调用只使用 API Key。不要将本机 YAML 复制进 `src/`、静态资源、构建产物或提交 Git，更换密钥在本机编辑。

```sh
npm run type-check
npm test
npm run build
```

`build` 先做类型检查，再构建 H5 与微信小程序；H5 产物位于 `dist/build/h5`。单独构建可使用 `npm run build:h5` 或 `npm run build:mp-weixin`。测试覆盖范围以 `tests/` 中实际用例为准。按用户要求，验收不再运行浏览器、截图或显示效果检查，页面实际效果由用户自行验收；构建成功不代表微信真机或生产上线验收通过。
