# 应届生求职资料库

整理与入口核查日期：2026-10-27。覆盖项目现有 16 个专业方向，优先应届生、实习与校园招聘准备。

资料包括两类原创内容：由既有专业提示卡生成的简历准备清单，以及本次依据官方学习资料编写的复习提纲。每份提纲给出学习步骤、练习或自测问题，并保留来源链接。内容是本项目整理，不是官方题库、招聘背书、职业资格培训或录用保证；学习资料不能被当作用户已经拥有的经历和技能。

## 来源与核查

- [技术、工程、科研与健康专业来源记录](tech-sources.md)，对应 [复习提纲](tech-materials.json) 和 [招聘入口](tech-portals.json)。
- [经管、人文、设计、教育与物流专业来源记录](general-sources.md)，对应 [复习提纲](general-materials.json) 和 [招聘入口](general-portals.json)。
- [已有原创专业简历提示卡](../resume-library/playbooks.json) 与 [参考资料边界](../resume-library/README.md)。外部简历原件不打包到服务，也不自动进入模型或 RAG。

招聘入口只表明核查当日可定位的官方申请渠道，不代表有具体在招岗位。地区、学历、语言、应届年份、执业资质、申请条件及截止日期以当期官方公告为准；国际机构和海外渠道须另行核对适用地区。未能核实的链接在来源记录中说明，不冒充可用岗位。`checkedAt` 是本项目核查时间，复习材料的 `updatedAt` 是本项目整理时间，均不冒充发布机构更新时间。

所有正文按纯文本阅读，只打包原创整理内容与公开来源元数据；未复制完整教材、试题或第三方简历，不因网页公开可读而推断拥有商业转载、模型训练或向量入库授权。本轮未创建知识库、调用真实模型或接入自动投递。

## 在产品内使用

从“发现”或“权益”打开求职工作台，在“复习资料”按专业与岗位筛选并阅读正文；在“招聘入口”筛选机构、复制官方链接自行核对具体公告。找到真实岗位后，可点击“录入已找到的岗位”，补全岗位名称、地点、要求和具体公告地址，随后使用保存的简历分析、审核修改、创建投递计划。系统不代发简历。

## 离线维护与构建

```sh
npm run career:build
npm run career:check
```

构建脚本离线读取本目录四份 JSON 和既有专业提示卡，通过与服务端相同的运行时校验生成 `server/assets/career/catalog.json`。`career:check` 检查来源结构、专业覆盖和产物是否过期；不会联网请求、读取私人数据或修改 `.data/`。服务端构建将这一公开资料包随字体等资源复制，正式发版仍需单独授权。

默认优先读取 `.data/career-catalog.json`；该文件不存在时使用打包资料。显式配置的目录不存在时保持空目录；已有目录为空或损坏时不以打包内容掩盖结果。自定义目录替换整个打包目录，不隐式合并。旧 `version: 1` 格式继续支持，招聘入口使用 `version: 2` 的 `portals` 数组，字段见共享契约 `CareerRecruitmentPortal`。私人简历、个人投递资料和外部原件始终保存在被忽略的本地目录，不能加入本公开资料包。

资料持续维护时先核实官方归属、入口可读性和地区适用范围，再修改正文、来源与核查时间，运行以上命令及相关行为测试。本轮仅完成首批基础准备材料，不声称资料已覆盖各专业全部课程或全部招聘企业。
