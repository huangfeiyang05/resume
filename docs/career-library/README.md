# 应届生求职资料库

初次整理日期为 2026-10-27，岗位与新增入口于 2026-11-13 核查。覆盖项目现有 16 个专业方向，优先应届生、实习与校园招聘准备。

资料包括两类原创内容：由既有专业提示卡生成的简历准备清单，以及本次依据官方学习资料编写的复习提纲。每份提纲给出学习步骤、练习或自测问题，并保留来源链接。内容是本项目整理，不是官方题库、招聘背书、职业资格培训或录用保证；学习资料不能被当作用户已经拥有的经历和技能。

## 在产品内使用

从“工作台”进入，在“复习资料”按专业与岗位筛选并阅读正文。在“公司岗位”可筛选校招、实习、社招及应届或实习机会，并从岗位详情复制官方公告链接。近期核对的具体岗位也出现在求职助手，能直接带入简历诊断。超过 30 天未复核的共享岗位退出助手结果，保留原始来源供复核。找到真实岗位后，可点击“录入已找到的岗位”，补全岗位名称、地点、要求和具体公告地址，随后使用保存的简历分析、审核修改、创建投递计划。系统不代发简历。

## 离线维护与构建

```sh
npm run career:build
npm run career:check
```

构建脚本离线读取本目录的岗位、复习提纲、历史招聘入口和既有专业提示卡，通过与服务端相同的运行时校验生成 `server/assets/career/catalog.json` 和原创岗位参考卡 `server/assets/career/role-guides.json`。`career:check` 检查来源结构、专业覆盖和产物是否过期。服务端构建将公开资料包随字体等资源复制。

默认优先读取 `.data/career-catalog.json`；该文件不存在时使用打包资料。显式配置的目录不存在时保持空目录；已有目录为空或损坏时不以打包内容掩盖结果。自定义目录替换整个打包目录，不隐式合并。旧 `version: 1` 格式继续支持，历史招聘入口保存在 `version: 2` 的 `portals` 数组中，供读取旧底稿和发布历史。私人简历、个人投递资料和外部原件始终保存在被忽略的本地目录，不能加入本公开资料包。

后台可按“只看待复核岗位”安排维护，核对官方详情后更新来源日期、岗位条件和开放状态，再对照发布。官网明确关闭时改为已关闭或下架，链接暂时无法判断时保留原核对日期。随包底稿变更继续运行以上命令及相关行为测试。本轮仅完成首批基础准备材料，不声称资料已覆盖各专业全部课程或全部招聘企业。
