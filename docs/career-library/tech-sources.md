# 首批理工农医求职资料来源核查

核查日期：2026-10-27（北京时间）。面向应届生、在校实习与校招基础准备；覆盖现有专业大类中的八类，不是每个教育部专业、岗位或考试的完整题库。

本目录的 `tech-materials.json` 是简历有方原创学习提纲，按“学习顺序 → 自行练习 → 自测问题 → 可保留的真实证据”组织。外链用于继续学习与核查主题背景，来源机构未参与本项目编写，也不为项目、招聘效果或能力判断背书。没有复制来源全文、试题、图片或附件，没有下载并再发布原件，没有接入模型训练或 RAG 索引。临床、危险实验、工程验收和产品合规判断均不由这些入门练习提供。

`updatedAt` 和 `checkedAt` 均记录本项目这次整理或访问核查日期，不是来源的发布日期，不意味着官方课程在当日更新。公开网页可读也不代表取得商业转载、改编或模型使用授权；后续若要导入原文或附件，须单独核实许可。

## 后续补充方向

- 软件、数据、机电等方向继续按目标岗位补专题，不把本批提纲称为完整面试题库。
- 土建需增加建筑与规划作品集指导，农食需增加田间研究、林学等分支，护理公卫需补国内院校与机构适用的学习入口。
- 招聘入口需要定期人工复核。没有独立核对岗位正文、用人单位、地点、适用人群与有效截止日期前，不生成“开放岗位”记录。
- 本批无第三方私人简历、真实患者/客户记录、账号、手机号、邮箱或下载附件，适合随项目分发的是原创提纲和来源链接；不将未获许可的资料原件加入发布包。
