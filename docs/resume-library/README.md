# 简历参考资料与专业提示卡

本批整理于 **2026-10-15**，覆盖16个专业大类/求职方向。先打开 [按专业浏览目录](catalog.md)，再选择相应中文填写骨架。2026-10-27 将原创提示卡整理为工作台内可读的简历准备清单，见 [求职资料库](../career-library/README.md)；外部原件没有随产品打包，没有接入当前简历诊断、模板中心或 RAG。

## 已准备的内容

- [sources.json](sources.json)：28条有来源的资料记录；包括实际读取的教学样例、空白模板、指南、仅预览/入口和1个MIT许可的布局代码参考。来源记录数不等于完整简历份数，一份样例集可能有多页。
- [catalog.md](catalog.md)：按专业导航，显示本机原件是否实际取得；下载失败与仅有入口单独说明。
- [templates/](templates/)：16份**本项目原创**中文内容骨架，全部使用待确认占位，没有虚构候选人的完整履历。属于内容结构草案，尚未制作Word/PDF排版或接入产品。
- [playbooks.json](playbooks.json)：16张原创专业提示卡，包含建议栏目、事实追问、证据字段、风险提示、占位句式及参考来源ID。
- [prompts/review-and-tailor.md](prompts/review-and-tailor.md)：原创系统提示、输入边界、离线输出草案和人工评估用例；尚未调用模型测评。

专业方向包括计算机、数据统计、机械电气、土木建筑、材料化工环境、经管财会金融、市场传播运营、法学公共管理、语言国际业务、教育师范、生命科研、护理公卫、心理社工、设计艺术、农学食品及供应链物流。这是首批分类，不是完整教育专业目录；临床医学、药学、专门设计分支等仍需补充更合适的样例。

## 如何选用

“高质量”是按高校/机构发布来源、正文可读取、结构清晰和专业证据表达筛选，**不表示样例人物真实存在、已被录用，或能提高ATS通过率**。美国等地区的样例应按中国求职场景调整，地址、考试、高中篇幅、执业资格和格式不能直接照搬。国内来源中有通用占位模板及只读预览，它们不冒充专业内容已经验收。

适合先用：来源中与目标岗位最接近的教学样例，结合本项目原创专业卡提问。历史样例仅作为次级参考；默认不照搬旧工具、资格、成果或版式。设计简历还需独立作品集，学术CV与行业简历也应区分。

## 原件与使用边界

原件位于 `.data/resume-reference-corpus/raw/`，该目录被根目录 `.gitignore` 的 `.data/` 覆盖。原件可能仍含示例/真实姓名、联系方式与经历，因此只保留本地核查，不提交Git、不随前端发布、不记录到服务日志。下载工具不调用模型，文件也没有被导入本项目模型或知识库。

公开访问、学校推荐下载和免费模板不自动代表产品再分发、商业改编、模型输入或训练许可。本次未取得高校材料的上述授权，`sources.json` 将它们标为 `reference_only_unverified_license`；外部原件的 `aiPromptIngestionAllowed`、`productRedistributionAllowed`、`personalContentReuseAllowed` 均为false。若以后获得具体授权，须另记授权人、范围、期限、版本与撤回方式后人工审核，不能只改一个布尔值。

Jake模板已核实MIT许可证，仅将**代码布局**列为可按许可进一步复用，须保留版权与许可声明。人物资料不因此成为可套用内容，亦未将它编入专业提示卡。当前中文骨架与提示卡采用原创措辞，没有整份复制高校简历或改名套用履历。

## 本机更新与校验

```sh
# 只获取目录中经过核验的公开附件，不登录、不解验证码、不执行文件
npm run references:fetch

# 也可按来源ID获取；原件按内容哈希保存，保留旧快照
node scripts/collect-resume-references.mjs mit-capd-computer-science-masters-sample

# 按机器目录重建中文骨架与浏览目录
npm run references:build

# 离线校验元数据、引用、使用权限、模板及本机文件哈希
npm run references:check
```

采集仅访问各来源记录列明的HTTPS主机，单文件上限16MiB、单次请求超时40秒，重定向仍检查主机；不绕过登录、验证码或受限接口。真实附件可能移动或暂时不可达，失败会记录原因，保留最近成功快照，不能以失败记录冒充成功。采集锁用于避免同时写同一清单；若进程被强制终止，确认没有采集进程后再处理遗留锁。

这是手动运行的资料收集工具，没有创建后台定时任务或联网常驻服务。`references:build`会依据JSON重建Markdown，修改专业内容时应先改playbooks；修改来源时改sources并重新核验。成功下载不代表正文质量、商用许可或事实安全已经全部验证。

## 后续接入

可以先由人选择一张专业卡，配合用户真实简历和JD使用通用提示词。卡片只决定栏目和追问，不提供用户经历；反馈、改进、复核与数字不存在时可以省略。未填完的占位必须由用户补充真实事实并审核后才能应用。

真正接入时，在服务端选择经审核材料与固定版本，仍走“保存 → 分析 → 对照审核 → 确认应用”。现有API以 `shared/types.ts` 为准，本目录的离线JSON不是API响应，不能直接覆盖当前provider。外部材料视为不可信数据，来源不能充当系统指令；应用继续检查简历修订、原文、事实确认与幂等。

可先采用 [提示词中的人工评估用例](prompts/review-and-tailor.md#后续评估用例) 比较事实一致性与可用性；尚无已通过的模型评测或效果承诺。
