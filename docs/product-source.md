AI 简历微信小程序

产品方案与开发设计说明书  ·  MVP V1.0  ·  2026-10

适用范围：独立开发者；微信小程序前端 + Spring Boot 后端 + 微信云托管 + 千问 API。本文价格与成本为待验证的产品假设。


## 1. 项目定位与 MVP 范围


定位：面向求职者的 AI 简历制作、诊断、岗位定制优化和 PDF 导出工具。商业路径：免费制作 → 免费 AI 诊断 → 广告解锁基础 PDF → 单次付费/会员解锁深度优化与免广告。

首版范围：微信登录、简历结构化编辑、PDF/Word 上传解析、3 套基础模板、AI 诊断、JD 粘贴与匹配、AI 深度优化、差异对比与逐项应用、PDF 导出、激励广告、订单支付、会员与额度、个人中心。暂不做职位爬虫、自动投递、多 Agent、向量库。


## 2. 用户与核心业务流程


登录 → 新建或上传简历 → 编辑与预览 → 免费诊断（首次 1 次）→ 选择基础模板 → 免费用户观看激励视频获得指定版本导出资格，或购买 ¥4.9 优化、¥9.9/7 天、¥19.9/30 天会员 → AI 结果逐项确认 → 导出 PDF。

重要：同一简历版本成功解锁后，建议 24 小时内重复下载免重复观看；广告不可用时提供可行的替代路径。AI 失败不扣次数，下载失败不重复消耗已授予的下载权限。


## 3. 套餐、权益与计费规则



| 权益 | 免费 | 单次 ¥4.9 | 7 天 ¥9.9 | 30 天 ¥19.9 |
| --- | --- | --- | --- | --- |
| 创建简历 | 1 份 | 1 份 | 5 份 | 20 份 |
| AI 诊断 | 首次 1 次 | 首次 1 次 | 包含在 AI 总额度内 | 包含在 AI 总额度内 |
| 深度优化 | 无 | 同一份 3 次 | 20 次 | 60 次 |
| JD 匹配 | 无 | 1 个岗位 | 20 次 | 60 次 |
| 模板 | 基础 3 套 | 高级模板 | 全部 | 全部 |
| PDF 导出 | 激励广告解锁 | 对应简历免广告 | 免广告 | 免广告 |
| 每日 AI 上限 | — | 按单次额度 | 10 次 | 无上限 |


产品规则：会员为一次性固定期限购买，不默认自动续费；会员有效期从支付成功起计算；优化额度按服务端原子预占/结算；不提供无限 AI 调用。付费单次权益只绑定购买时指定的简历。会员次数、诊断次数和岗位匹配次数的计费口径需在页面明确展示，建议统一成“AI 服务次数”并标示各操作扣减规则，避免双重计数歧义。

会员升级：可以测试单次订单在 24 小时内抵扣部分会员费用，但需另设升级订单与权益回收/转换逻辑；首版可以暂不支持。

## 5. 系统架构与部署


微信小程序（uni-app/Vue 3） → 微信云托管调用链路（wx.cloud.callContainer） → Spring Boot 3 / Java 17 模块化单体 → MySQL、Redis（可选）、私有对象存储、千问 API。PDF 生成使用受限 Chromium/Playwright 容器或独立任务服务。

部署建议：先在本地开发，测试环境部署云托管；生产环境使用独立环境、独立 API Key、独立数据库与对象存储。云托管不是免费无限资源；检查 CPU/内存、实例缩容、数据库、存储、流量、构建与出网费用。调用千问 API 需要验证出网能力及网络配置。

域名：采用微信云托管与小程序内部调用时，通常不必单独购买用于前端调用的 API 域名；如需浏览器公开访问、第三方回调、独立 H5 或自定义 API 入口，可能需要域名、HTTPS 及相应备案。具体以当期微信/云平台配置为准。

## 7. 核心 API 草案



| 方法与路径 | 功能 |
| --- | --- |
| POST /api/v1/auth/wechat | 微信 code 换取服务端会话 |
| POST /api/v1/resumes | 新建简历 |
| GET /api/v1/resumes/{id} | 读取本人简历 |
| PUT /api/v1/resumes/{id} | 乐观锁更新简历 |
| POST /api/v1/resumes/import | 上传并解析文件 |
| POST /api/v1/ai/tasks | 发起诊断/优化/JD 匹配任务 |
| GET /api/v1/ai/tasks/{id} | 查询状态和结果 |
| POST /api/v1/ai/tasks/{id}/apply | 逐项应用优化建议 |

| GET /api/v1/exports/{id} | 查询导出结果及短时下载地址 |

API 统一返回 code/message/data/requestId；接口认证与资源归属检查放在服务端。长耗时 AI/PDF 采用异步任务 + 轮询，后续按需增加 SSE。


## 8. AI 工作流与防幻觉设计


导入解析 → 结构化 JSON → 诊断 → JD 关键词/能力匹配 → 深度优化 → JSON Schema 校验 → 事实风险标注 → 用户逐项确认 → 保存新版本。每次任务固定原始版本快照和 input_hash，防止用户编辑后错应用旧建议。

建议模型输出字段：summary、suggestions[{sectionId,fieldPath,originalText,optimizedText,reason,priority,requiresConfirmation,missingInformation,jobAlignment}]。禁止虚构工作单位、学历、日期、技能熟练度、成果指标；若缺少量化数据，应提出待补充问题，不直接编造。

模型策略：千问 Flash 用于解析/初步诊断，较强模型仅用于复杂优化；先进行 A/B 质量测试，再决定是否升级。严格设置 max tokens、超时、重试次数、输入长度和预算上限。


## 9. 广告解锁与支付安全


激励广告：前端展示广告 → 平台完成事件 → 服务端校验可信奖励证明（以当前平台能力为准）→ 写入唯一解锁记录 → 生成对应简历版本的短期导出资格。仅收到前端 isEnded=true 不可视为强验证；如平台缺乏服务端验证能力，应采用保守限额、风控和异常审计。

微信支付：创建订单 → 服务端调用支付接口 → 前端发起支付 → 服务端验签支付回调并主动核单 → 幂等发放会员或单次权益。前端支付成功提示不能作为最终入账依据。退款需对应撤销或调整尚未消耗的权益。


## 10. API Key、用户隐私与滥用防护


千问 API Key 只存储在云托管的安全环境配置/密钥管理中，不写进小程序、Git、日志、镜像或错误信息。使用独立 Key、最小权限、定期轮换、成本告警与异常熔断；发现泄露立即吊销并更换。

所有 AI 请求必须经过服务端身份验证、额度校验、原子预占、限流、并发控制、请求大小限制；禁止前端自行声明会员状态。文件私有存储、签名短期下载、对象键不可预测、严格检查 MIME/大小/恶意文件。

简历含手机号、邮箱、工作履历等个人信息：最小化采集，提供隐私政策、第三方模型处理告知、删除和注销能力；敏感字段日志脱敏；生产与测试数据隔离；备份加密并定义保留期限。


## 11. 成本、盈利与指标


套餐定价：¥4.9 单次、¥9.9/7 天、¥19.9/30 天。以下为假设测算，非供应商实时报价：若 AI 优化 ¥0.05/次、JD 匹配 ¥0.01/次，7 天会员各使用 20 次，则模型成本约 ¥1.20；30 天各使用 60 次则约 ¥3.60。实际还需计入云托管、数据库、文件存储、PDF 渲染、微信支付手续费、广告收益波动、获客、退款、税费。

核心指标：简历创建完成率、诊断使用率、广告完成率、广告解锁导出成功率、4.9 元购买转化率、会员转化率、每付费用户 AI 调用次数、单用户贡献利润、退款率、模型失败率、PDF 生成时长。广告收益不应作为首期主要盈利预测。


## 12. 开发计划与验收标准



| 阶段 | 交付内容 | 验收重点 |
| --- | --- | --- |
| 第 1–2 周 | 微信登录、编辑器、版本、模板、PDF | 可创建/保存/导出基础简历 |
| 第 3 周 | 上传解析、AI 诊断、JD 优化、差异确认 | 不编造事实、错误可恢复 |
| 第 4 周 | 订单、会员、额度、广告解锁 | 回调幂等、并发不超扣 |
| 第 5 周 | 云托管部署、监控、隐私与安全 | 密钥不外泄、文件不越权 |
| 第 6 周 | 小规模灰度、修复与数据验证 | 真实用户端到端流程通过 |


上线门槛：支付与退款测试、广告未完成/无填充场景、AI 超时/重复请求、用户越权访问、下载链接过期、个人信息删除、费用上限预警、数据库备份恢复演练全部通过。


## 13. 上线前待确认事项


① 微信小程序主体、服务类目与备案；② iOS 端数字化服务支付规则；③ 微信支付商户资质；④ 流量主激励视频开通门槛及服务端奖励验证能力；⑤ 云托管资源报价与免费额度；⑥ 千问 API 当前价格、权限和数据处理条款；⑦ 生成式 AI 服务与个人信息保护相关合规义务。以上应以平台当期官方政策为准。

结论：优先完成“免费制作 + 广告导出 + 4.9 元优化 + 9.9 元短期会员”的可付费闭环。先验证真实转化和用户满意度，再考虑职位信息库、面试模拟等扩展。
